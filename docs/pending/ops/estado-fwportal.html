Comandos

Ver el log:

tail -20 /var/log/byte-api.log

Ver la base:

sqlite3 /var/db/byte/portal.db 'select ip,mac,phone,kind,start_at,end_at from access order by start_at desc limit 5;'
sqlite3 /var/db/byte/portal.db 'select name,phone,verified_at from verified order by verified_at desc limit 5;'

Reiniciar la API (en OPNsense, dentro de sh -c '...'):

pkill -x byte-api; sleep 2; set -a; . /usr/local/etc/byte/apikey.env; set +a; export OPNSENSE_URL=https://127.0.0.1 OPNSENSE_SERVER_NAME=fwportal.byteservices.net OPNSENSE_ZONE=0 ADDR=127.0.0.1:8085 DB=/var/db/byte/portal.db PORTAL_DIR=/usr/local/www/byte TIMEZONE=America/Caracas RESET_AT=02:00; daemon -p /var/run/byte-api.pid -o /var/log/byte-api.log /usr/local/sbin/byte-api; sleep 3; tail -3 /var/log/byte-api.log
